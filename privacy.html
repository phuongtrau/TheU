Privacy policy

TheU Uploader · effective 25 November 2026

TheU Uploader is the publishing tool of the YouTube channel The Unrationalist. Only the channel owner uses it, and only to manage that one channel. It is not offered to other users.

What Google user data it accesses

When the channel owner signs in with Google, the tool requests these permissions:

  • YouTube (youtube.force-ssl): to identify the signed-in channel, upload the channel's videos, set their thumbnails, add captions and add videos to the channel's playlists.
  • YouTube Analytics (yt-analytics.readonly): to read the channel's own audience-retention and performance reports.

How the data is used

The data is used only to publish and evaluate The Unrationalist's own videos. The tool checks the channel ID of the signed-in account and refuses to upload to any other channel. It does not access other users' data, does not use the data for advertising, and does not sell, rent or share it with anyone.

Storage and security

The OAuth refresh token is stored only on the channel owner's computer, in a file that only the owner's user account can read. It is never published or sent anywhere other than Google's own OAuth and YouTube API endpoints. Analytics reports are saved on the same computer. No data is stored on any server operated by The Unrationalist.

Retention and deletion

Data is kept only while it is needed for the purposes above. Access can be revoked at any time at myaccount.google.com/permissions; the stored token then stops working, and the owner deletes it from their computer.

Google API Services User Data Policy

TheU Uploader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It uses the YouTube API Services, and by using it you also agree to the YouTube Terms of Service; see the Google Privacy Policy.

Questions about this policy: use the contact details on the channel's About page.
